# This Was Supposed to be a Fighting Story — website

A single-page, retro-internet-style reading site for Black John's book.

## Included
- `index.html` — homepage, chapter directory, and all eight approved public chapters.
- `style.css` — visual styling and responsive layout.

## Publish with GitHub Pages
1. Upload `index.html` and `style.css` to the root of your GitHub Pages repository.
2. Commit the files to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait a few minutes and open `https://YOUR-USERNAME.github.io`.

## Privacy / unpublished material
Only chapters 1–8 from the supplied manuscript are included. No other chapter text or the source Word document is included in this website package. The public site is not password protected; do not upload private chapters to a public repository.

## Notes
The page uses Google Fonts when internet access is available and falls back to local serif/monospace fonts otherwise.
